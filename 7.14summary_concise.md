## Teleop Recording Notes

Quest3 adapter should use:

```bash
-p rotation_scale:=0.0
```

If moving left causes anticlockwise rotation, likely cause is startup synchronization:

- `/current_pose` not stable yet
- stale `/target_pose`
- adapter not re-anchored
- recorder started too quickly

Before each recording:

```bash
pkill -f quest3_stream_adapter
pkill -f record_lerobot_format_leader_follower
pkill -f starvla_franka_delta_pose_client
ros2 topic echo /current_pose --once
ros2 topic info -v /target_pose
```

Then restart adapter/recorder, wait 5-10 seconds, press re-anchor/reset, test small motion, then record.
